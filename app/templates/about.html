Plasmid Editor

Sequence editing, annotation, restriction analysis, cloning simulation and sequencing alignment for the Gardiner Lab. It is the general-purpose companion to the MoClo Library Tool: use the MoClo tool to manage a Golden Gate parts library and plan modular assemblies, and this editor whenever the work is not MoClo based — aligning sequencing reads, classical restriction cloning, Gibson assembly, Gateway reactions, primer design, or simply manipulating DNA by hand.

Attribution

The functionality of this tool is modelled on ApE (A Plasmid Editor) by M. Wayne Davis, the desktop program this lab has used for years. ApE is a closed-source Tcl/Tk application, so none of its code is used, bundled or derived from here: the features were re-implemented independently in Python and JavaScript against published algorithms and standard libraries. Where ApE's conventions are useful for interoperability they are followed deliberately — ApE's tab-separated feature-library format is read and written unchanged, and ApE's ApEinfo_fwdcolor / ApEinfo_revcolor GenBank qualifiers are honoured, so files move between the two programs without losing annotations or colours.

If you use this tool in published work, please cite ApE as the origin of the feature set, and note which analyses were run here:

Davis MW, Jorgensen EM (2022). ApE, A Plasmid Editor: A Freely Available DNA Manipulation and Visualization Program. Frontiers in Bioinformatics 2:818619. doi:10.3389/fbinf.2022.818619

ApE itself is available from jorgensen.biology.utah.edu/wayned/ape. This project is not affiliated with or endorsed by its author.

Other software used
  • Biopython — sequence file parsing, REBASE enzyme data, pairwise alignment, melting temperatures. Cock PJA et al. (2009) Bioinformatics 25:1422–1423.
  • REBASE — restriction enzyme recognition sites and cut positions, via Biopython. Roberts RJ et al. (2015) Nucleic Acids Res 43:D298–D299.
  • Flask — the web framework.
How it fits with the MoClo Library Tool

The two tools run side by side on the same server and share the MoClo databases. Parts, backbones and assembled plasmids from the MoClo tool can be opened here for editing or read alignment.

In the other direction, any plasmid in this editor can be ticked as Golden Gate ready. The editor then checks that a single Type IIS enzyme releases exactly one clean insert with two 4 bp fusion sites, and offers to add it to the shared MoClo parts library — stored the way the MoClo tool expects, with both fusion sites included, so it is immediately usable in assemblies there. Plasmids that are not Golden Gate compatible stay in this editor only, and the reason they cannot be contributed is reported.

The shared logic lives in a standalone dnakit package inside this repository, so the MoClo tool can adopt it later instead of keeping its own copies of the restriction, translation and export routines.
